Screen capture isn’t available here

Most mobile browser configurations do not expose screen capture to web pages. If an Android Chrome build or experimental flag exposes getDisplayMedia(), this recorder enables itself automatically; otherwise, open this page in current Chrome, Edge, or Firefox on a desktop computer.

The original 2017 two-device Android relay depended on a retired PeerJS server and obsolete capture flags. This version fails honestly instead of pretending that connection still works.
